# ⚡ DODO Performance & Hardware Optimization

## Target Hardware Profile

DODO is engineered for consumer laptop hardware with hardware-aware resource allocation:

- **Host RAM**: 16.0 GB DDR4/DDR5
- **GPU**: NVIDIA GeForce RTX 3050 Laptop GPU
- **VRAM**: 4.0 GB GDDR6 (3.2 GB safe allocation headroom)
- **CPU**: 16 Logical Cores (x64 Windows 11)
- **Local AI Provider**: Ollama v0.40.15 (127.0.0.1:11434)
- **Active Model**: `qwen2.5-coder:1.5b` (986 MB, Q4_K_M quantization)

## Performance Optimizations Implemented (Phase 8)

1. **Context Window Token Budgeting**:
   - `ContextManager.assemble_planning_context` enforces a strict 4096-token boundary to prevent GPU OOM on 4GB VRAM.
   - Long-term memory injection is budgeted to max 400 tokens per prompt.
2. **Playwright Chromium Lifecycle Optimization**:
   - Process reuse across tab navigations avoids repetitive browser process launch overhead.
   - Graceful transport teardown prevents Windows pipe leaks.
3. **Database Caching & Non-Destructive Upsert**:
   - Bounded cursor queries (`limit=50`, `skip=0`) prevent unbounded memory consumption.
   - Disk persistence batches mutations during idle periods.
4. **Streaming Inference via Server-Sent Events (SSE)**:
   - Tokens stream directly to UI as they are generated by Ollama, providing immediate interactivity.
